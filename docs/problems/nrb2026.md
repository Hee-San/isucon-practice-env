# ISUNARABE 合同演習2026(nrb2026)

## 問題を読む

- [問題の仕様(API・スコアの決まり・critical エラーの一覧)](https://github.com/KOBA789/nrb2026/blob/main/docs/idea.md)
- [作問リポジトリ](https://github.com/KOBA789/nrb2026)([作問記](https://github.com/KOBA789/nrb2026/blob/main/POSTMORTEM.md))

椅子の共同購入サービス「Isupon」です。決められた人数が集まると約定し、参加者に課金されます。
公開されている資料は上の作問リポジトリだけです(当日マニュアルや解説動画はありません)。

本番の初期実装は Rust だけでしたが、この環境では **同じ外部仕様を Go に移植したもの**(このリポジトリの [`nrb2026/webapp/go`](https://github.com/Hee-San/isucon-practice-env/tree/main/nrb2026/webapp/go))を動かします。
遅い作り(派生値の都度計算、N+1、性能のためのインデックス無し、webhook の同期送信、画像を毎回 DB から返す)も Rust 版のまま移してあります。

## サーバの中身

isu1〜isu3 の3台とも同じです。ベンチは既定で isu1 に向けます。

| 場所 | 中身 |
|---|---|
| `/home/isucon/webapp/go` | Go の初期実装。直したら `go build -o nrb2026 . && sudo systemctl restart nrb2026-go` |
| `/home/isucon/webapp/sql` | `schema.sql` と `seed.sql`(椅子 1505 件、画像入り)。`POST /api/initialize` がここを `mysql` コマンドで流す |
| `/home/isucon/webapp/public` | ビルド済みのフロントエンド。アプリが 80 番で API と一緒に直接配る(nginx はありません) |
| サービス `nrb2026-go` | アプリ(80 番)。ログは `journalctl -u nrb2026-go` |
| MySQL 8.0 | ユーザー `isucon` / パスワード `isucon`、DB `nrb2026`。127.0.0.1 だけで待ち受け |

## ベンチを回す

本番でポータルに集まっていたスコアは、ベンチの出力で見ます。
打つ前にチームのチャンネルで宣言してください(同時に打つと互いのスコアが壊れます)。
bench 機ではアプリが動いていないので、止めるものはありません。

`ssh bench` で入って、次を実行します。2分ほどで最後に `score: {"score":...}` が出ます。

```bash
~/bench.sh
```

- isu1 以外に向けるときは、`~/bench.sh 192.168.0.12` のように IP を渡します
- 点数は「約定したキャンペーンの参加者数 × 1000」から、ソフトエラー(10秒のタイムアウトなど)1件ごとに 100 点を引いたものです。ソフトエラーが 50 件に達するか、二重課金などの critical エラーが1件でも出ると 0 点です
- 初期状態ではタイムアウトが 50 件に達して 0 点になることがあります(手元で試したかぎり、Rust の初期実装でも同じでした)。出力の `[SOFT]` の行で、どの API が遅いかが分かります

## 本番との違い

- 初期実装が Go です(本番は Rust を debug ビルドのまま `cargo run` で起動していました)
- 公開された AMI が無いので、素の Ubuntu 24.04 に起動時に組み立てます。そのため作成に15分前後かかります
  (組み立ての中身は [`nrb2026/provision.sh`](https://github.com/Hee-San/isucon-practice-env/blob/main/nrb2026/provision.sh)。ログは各サーバの `/var/log/nrb2026-provision.log`)
- ベンチ・seed・フロントエンドは、作問リポジトリの公開時点のもの(コミットを固定)をビルドして使います。seed は本番の配布物と同じ件数・乱数の種(1500件、`0xC0FFEE`)で作ります
- ポータル・benchwarmer・isuwari はありません。ベンチ機の IP は 192.168.0.10 です(本番は 192.168.0.100)
- ベンチ機は `c5.xlarge` です(本番は競技サーバと同じ `c5.large`)
